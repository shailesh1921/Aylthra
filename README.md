> A modern, responsive full-stack eCommerce application designed for curated fashion apparel. Features role-based administration, end-to-end shopping cart workflows, dynamic discount coupon validations, and a hardened Express.js REST API with 15+ secure endpoints.

---

## 🚀 Key Modules & Engineering Features

### 1. 🛒 Full-Stack Shopping Experience
- **Interactive Catalog**: Real-time category filtering, price sliders, search indexing, and customer review modules.
- **Cart & Wishlist Architecture**: State-managed cart and persistent wishlist with local storage synchronization and promo coupon validation.

### 2. 🔐 Secure RESTful Backend (15+ Endpoints)
- **Authentication**: JWT (JSON Web Tokens) with secure HTTP-only cookies and bcrypt password hashing.
- **Role-Based Access Control**: Strict segregation between shopper privileges and administrative product management.
- **Defensive API Hardening**: Secured with **Helmet**, CORS policies, and Express **rate-limiting middleware** to protect against brute-force attacks.

### 3. 📊 Admin Inventory Dashboard
- Dedicated portal for inventory creation, batch stock updates, image uploads, order fulfillment status tracking, and revenue overview.
